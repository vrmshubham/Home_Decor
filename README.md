# Home Decor Store

Monorepo for an Indian home-furnishing store serving Bhavnagar locally and customers across India.

## Planned stack

- Frontend: React + TypeScript
- Backend: Django REST Framework
- Database: PostgreSQL
- Payments: Razorpay
- Product media: Cloudinary or S3-compatible storage
